## Highlights

### HUB75 Transit Tracker Display on ESP32

* Uses DMA to drive a HUB75 LED matrix while fetching and parsing GTFS-Realtime data every 30 seconds. 
* Designed around task isolation to keep display timing independent from networking and parsing.
* RTOS infrastructure: separates tasks to prioritize display while ensuring constant updates and healthy CPU usage
